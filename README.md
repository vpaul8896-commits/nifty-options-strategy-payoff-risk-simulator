# nifty-options-strategy-payoff-risk-simulator
# NIFTY Options Strategy Payoff & Risk Simulator

**Tools:** Microsoft Excel 2021 | Microsoft Power BI

## Project Overview

An Excel-based financial modelling tool integrated with Power BI to analyse NIFTY options strategies, calculate expiry payoffs and evaluate risk-reward characteristics.

## Key Features

- Supports 11 NIFTY options strategies.
- Automated option-leg and combined P&L calculations.
- Maximum profit and maximum loss analysis.
- Breakeven point and risk-reward calculations.
- Expiry payoff analysis across 41 price scenarios (80%–120% of spot price).
- Scenario analysis under seven market movements (-10% to +10%).
- Excel dashboard with KPI cards and payoff chart.
- Power BI dashboards for Overview, Scenario Analysis and Payoff Curve.

## Technologies Used

- Microsoft Excel 2021
- Microsoft Power BI

## Supported Strategies

1. Long Call
2. Long Put
3. Short Call
4. Short Put
5. Bull Call Spread
6. Bear Put Spread
7. Long Straddle
8. Short Straddle
9. Long Strangle
10. Short Strangle
11. Iron Condor

## Project Structure

- `Excel_Model/` – Excel simulator workbook.
- `PowerBI_Report/` – Power BI report.
- `Screenshots/` – Project screenshots.
- `Documentation/` – Detailed project documentation.

## Limitations

- Expiry payoff analysis only; no live market data.
- No option Greeks, implied volatility or time decay calculations.
- Brokerage, taxes and slippage are excluded.
- Power BI visualises the currently selected strategy calculated in Excel.

## Disclaimer

This project is developed for educational and portfolio-demonstration purposes only. It is not investment advice or a recommendation to trade options.
